☠️ Objetos Amaldiçoados — Como funciona

Por contrato spawna 1 dos 7 objetos num ponto fixo do mapa (aleatório). Cada objeto tem custo de sanidade e risco diferente. Clica no mapa para ver as 7 localizações exatas + filtro por objeto.

🔮 Tarot · 🪞 Espelho · 🪆 Voodoo · 📻 Ouija · 🎵 Music Box · ⭕ Summoning Circle · 🐒 Monkey Paw — usa o filtro abaixo para destacar.
⏱️ Cronómetro da Carrinha — Tempo Real

Phasmophobia não tem API oficial — por ficheiros não dá para ler EMF/som/cronómetro ao vivo (só RAM). Criei 2 modos: Manual (1 clique, sempre funciona) e Auto via Bridge (script Python faz OCR da carrinha + lê SaveFile).

✓ Manual sem instalação Auto com phasmophobia-live-bridge.py
Como “ligar” o jogo?
Modo manual ativo — carrega INICIAR quando fechas a carrinha.
  1. Manual: escolhe dificuldade → INICIAR ao sair da carrinha
  2. Auto: corre python phasmophobia-live-bridge.py → liga Auto
  3. Atualiza sanidade nos sliders ou deixa o OCR ler a carrinha
💡 Ficheiros: .../LocalLow/Kinetic Games/Phasmophobia/SaveData.txt só guarda perfil (nível/dinheiro) no lobby — EMF/som/cronómetro nunca vão para disco, só RAM → precisa OCR ou mod BepInEx.

O que dá para ler por ficheiros? (resposta honesta)

EMF, som, cronómetro e sanidade AO VIVO não estão em ficheiros. O jogo mantém isso só em RAM e desenha no ecrã da carrinha. Os ficheiros em disco são:

  • SaveData.txt em %USERPROFILE%/AppData/LocalLow/Kinetic Games/Phasmophobia/ (Proton: .../compatdata/739630/pfx/.../Phasmophobia/) — guarda nível, dinheiro, prestígio, inventário só quando voltas ao lobby. Desde 2024 está ofuscado/encriptado mas o bridge tenta ler.
  • Player.log — só logs de arranque, sem telemetria.
  • Nada sobre EMF gráfico, microfone parabólico ou timer — confirma com tail -f SaveData.txt durante missão: não muda.

Soluções reais implementadas neste projeto:

  1. Ficheiros (seguro, já funciona): o phasmophobia-live-bridge.py vigia o SaveFile e preenche automaticamente o teu perfil (nível/dinheiro) quando voltas ao lobby.
  2. OCR da carrinha (recomendado para ao vivo): o bridge captura a zona do cronómetro/sanidade/EMF no monitor e faz Tesseract OCR → expõe em http://localhost:8765/status. O guia consome e atualiza cronómetro + sanidade em <1s. Precisas calibrar ROIs com --calibrate. Sem leitura de memória, indetetável.
  3. Mod BepInEx (máxima precisão, risco): plugin C# lê memória e expõe HTTP real. Não incluído por defeito — pode ser flagged pelo anti-cheat. Se quiseres, digo como compilar.
ℹ️ Testa: corre python phasmophobia-live-bridge.py --calibrate → abre /tmp/phasmo-calibrate.png → ajusta ROI_TIMER no .py → python phasmophobia-live-bridge.py → no guia liga Auto (Bridge). O cronómetro da carrinha e o teu perfil passam a atualizar sozinhos; se o OCR falhar, o modo manual continua.
Ver comandos de instalação — Windows / Linux 
Windows (recomendado):
# 1. Instala Python https://python.org (marca Add to PATH)
# 2. Instala Tesseract https://github.com/UB-Mannheim/tesseract/wiki -> tesseract-ocr-w64-setup-*.exe (marca Add to PATH)
# 3. Duplo clique em run-bridge-windows.bat  OU manual:
pip install flask flask-cors mss pillow pytesseract watchdog
python phasmophobia-live-bridge.py --calibrate
python phasmophobia-live-bridge.py
# Alternativa PowerShell: powershell -ExecutionPolicy Bypass -File install-windows.ps1

Linux:
sudo pacman -S tesseract tesseract-data-por tesseract-data-eng  # ou apt install tesseract-ocr
pip install flask flask-cors mss pillow pytesseract watchdog
python phasmophobia-live-bridge.py --calibrate
python phasmophobia-live-bridge.py
# no guia: Carrinha Ao Vivo -> Auto (Bridge) ON
